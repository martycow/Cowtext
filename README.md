# Cowtext

A desktop context-graph editor for AI-agent orchestration. Wire Memory Nodes (`.md` files from your project) into a visual graph, then **Compile** to generate production-grade `CLAUDE.md`, `AGENTS.md` (the 30+-agent industry standard), and `.cursor/rules` from a single source of truth. **Assemble** nodes on demand via headless `claude -p`, and watch live Claude Code hooks drive a 16-bit isometric barn scene.

Built on Tauri 2, React 19, PixiJS 8, and Rust.
